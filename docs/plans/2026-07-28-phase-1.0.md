# Phase 1.0 Ecosystem Implementation Plan

> **REQUIRED SUB-SKILL:** Use autonomous-atomic, test-driven-development, and verification-before-completion task-by-task.

**Goal:** Ship documented Go, browser-WASM, gRPC, and compile-time plugin entry points over the existing PathCraft engine.

**Architecture:** Keep `pkg/pathcraft/engine` as shared facade. Add one reader-based OSM load path, thin WASM and gRPC adapters, generated protobuf clients, and evidence-backed docs. Reuse existing plugin registry unchanged.

**Tech Stack:** Go 1.25+, `io`/`crypto/sha256`, Go `js/wasm` and `syscall/js`, Protocol Buffers, grpc-go, Node 24 smoke test.
