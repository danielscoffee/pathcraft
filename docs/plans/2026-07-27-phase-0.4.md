# Phase 0.4 Performance and Scale Implementation Plan

> **REQUIRED SUB-SKILL:** Use autonomous-atomic, test-driven-development, and verification-before-completion task-by-task.

**Goal:** Add exact degree-two graph contraction, safe preprocessing caches, concurrent query evidence, and reproducible memory profiling without breaking current routes.

**Architecture:** Keep immutable base graph and add serialized directed-chain index. A* queries contracted chain view with arbitrary endpoint access and expands original path nodes. Reuse stdlib SHA-256, atomic rename, goroutines, Go benchmarks, race detector, and pprof.

**Tech Stack:** Go 1.25+ standard library, existing graph/A*/engine/CLI packages, gob cache payload.
